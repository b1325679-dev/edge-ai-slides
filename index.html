第 1 頁：什麼是邊緣 AI？ — 把「大腦」裝進你的安全帽

概念生活比喻一句話重點
雲端 AI把路況影片拍下來 → 傳給遠端超級電腦分析 → 等回傳結果「打電話問專家」，有網路才能用、有延遲
邊緣 AI你的手機/車機自己就有個小腦袋，現場看現場懂「隨身帶專家」，離線、即時、隱私不出門
  • 為什麼機車安全必須是 Edge AI？
    • 🚦 0.1 秒生死時速：前方斑馬線、紅燈或切車，雲端還來不及。
    • 📶 無訊號地區（隧道、山路、地下道）：邊緣 AI 仍然能工作。
    • 🔒 影像不上傳，隱私零風險。

金句：Edge AI = 把偵測模型壓縮到手機大小，隨時隨地當你的第二雙眼睛。

第 2 頁：資料標註與模型訓練 — 教 AI 辨認「路況字母表」

步驟 1：收集「教科書」——多樣化照片

  • 日間 / 夜間 / 雨天 / 陰影 / 強光
  • 比喻：讓學生看遍各種字體寫法，避免把「斑馬線」誤認成裂縫。

步驟 2：在 CVAT 平台上「圈圈畫畫」——多類別標註

標註項目圖框顏色關鍵細節
🛵 機車騎士紅框含乘客、載貨、側身
🦓 斑馬線白框磨損、樹蔭、濕地反光
🚦 號誌燈綠/紅/黃框倒數計時、閃爍、遮擋

工具鏈：用 Docker 一鍵把團隊的標註匯出成 YOLO 格式（簡單的圖像標記標準）。

步驟 3：訓練一款「極速畢業生」模型

  • 使用 YOLOv8n（一個非常輕量版），只佔全功能版本的 1/10 參數，但仍能 即時偵測。
  • 目標：mAP@0.5 > 0.9（十張圖九張以上正確框出）。
  • 比喻：像換掉一本巨大的圖書館，考試仍考第一名。

第 3 頁：模型瘦身與手機整合 — 讓大腦塞進口袋

1️⃣ 量化（把「浮點數精算師」變成「整數會計師」）

階段檔案大小速度提升精度損失
訓練完成PyTorch .pt~6 MB基準0%
匯出TensorFlow Lite .tflite (FP16)~3 MB↑ 1.5×< 0.5%
量化後LiteRT / TFLite INT8~1.5 MB↑ 3–4×< 1%

白話：原本模型算 0.7321 × 0.9999，現在改算 73 × 100，快 4 倍、小 4 倍、眼神差不到 1%。

2️⃣ Android CameraX — 「相機管家」幫你餵資料

val analyzer = ImageAnalysis.Builder()
    .setTargetResolution(Size(640, 640))   // YOLO 喜歡正方形
    .setBackpressureStrategy(STRATEGY_KEEP_ONLY_LATEST) // 只處理最新畫面，不卡頓
    .build()
analyzer.setAnalyzer(cameraExecutor) { imageProxy ->
    detector.detect(imageProxy)   // 推論
    imageProxy.close()            // 釋放緩衝區
}

關鍵： STRATEGY_KEEP_ONLY_LATEST = 永遠只看最新一幀，舊畫面直接丟，手機不會發燙卡頓。

3️⃣ 雙執行緒架構 — 分工不搶路

執行緒負責輸入產出比喻
Thread A靜態標線每 3–5 幀 1 次斑馬線、停止線、車道線多邊形「路況地圖繪製師」：慢工出細活
Thread B動態物件每幀跑機車、行人、車輛 BBox + ID「動態雷達兵」：眼快手快

成果： 單核手機也能穩定 ≥ 30 FPS，Thread A 不拖慢 Thread B，紅燈前車輛不漏框、斑馬線不斷線。

部署檢查清單（給工程師）

  • 放入 assets/ 目錄：.tflite + labelmap.txt
  • 設定 Android minSdk 24、開啟 hardwareAccelerated="true"
  • 測試機型：入門機（Helio G85）至少跑 25 FPS
  • 電量測試：連續推論 1 小時電量下降 < 10%
